# Contributing

This repository is a published copy of the source of [isaacadjei.me](https://isaacadjei.me). Changes are made at the source and published here. That means a pull request cannot be merged directly, so please open an issue instead.

## Useful things to report

- A typo, broken link or factual mistake in the site's content
- A bug on the live site, with the page and steps to reproduce it
- An accessibility problem such as poor contrast or a missing label
- A security concern, which should follow [SECURITY.md](SECURITY.md) and never go in a public issue

## Not taken

- Feature requests and design changes. The site is a personal project with a fixed direction.
- Requests to add or reorder content.

## What happens to a report

I read each issue and apply accepted fixes at the source. They appear here in the next publish. I will reference the issue when they do.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).
