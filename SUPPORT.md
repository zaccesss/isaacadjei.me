# Support

> Public version of this page: https://isaacadjei.me/support

This is a personal site and this repository is a read only copy of its source, so there is no formal support.

- **Something wrong on the site or in the content:** open an issue using the templates provided.
- **A question about the code:** open an issue and label it as a question.
- **Anything else:** contact@isaacadjei.me

> [!WARNING]
> A security concern must follow [SECURITY.md](SECURITY.md) and must not be posted publicly.
